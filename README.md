# 🎬 Operator Helper

Electron-приложение и веб-интерфейс для оператора: AI-анализ чатов через DeepSeek, библиотека фраз, тип-меню, цели, музыка и база опыта со статистикой.

## Требования и запуск

- Node.js 22.5 или новее (используется встроенный `node:sqlite`).
- API-ключ DeepSeek.

```bash
npm install
npm run app        # настольное Electron-приложение
npm start          # веб-сервер: http://localhost:3000
npm test           # все автоматические тесты
npm run dist       # Windows installer и portable-сборка в dist/
```

В приложении откройте «Настройки», укажите ключ и профиль модели. В Electron ключ хранится через `safeStorage` (DPAPI в Windows) и не возвращается renderer-процессу. В веб-версии ключ остаётся на сервере.

## Работа с чатами и опытом

Рабочие чаты сохраняются в `localStorage`, автоматически обновляются при вводе и удаляются через 30 дней. Кнопка «Очистить все чаты» очищает только это локальное хранилище.

Чат можно отдельно сохранить в базу опыта и отметить его результат. База опыта хранится в SQLite и очищается отдельной кнопкой на вкладке «Опыт». Примеры из неё передаются модели как недоверенные данные, а не как системные инструкции.

Файлы заготовок лежат в `data/`:

- `Зазывы в приват.txt` — библиотека фраз EN/RU;
- `tipmenu.json`, `goals.json`, `goal-bank.json` — тип-меню и цели.

## Веб-сервер и безопасность

Локально сервер слушает только `127.0.0.1`. При сетевом запуске (`HOST=0.0.0.0`) используются два уровня доступа:

- `ACCESS_TOKEN` — обычный доступ к сайту и генерации;
- `ADMIN_TOKEN` — настройки ключа и все операции с базой опыта.

Если токены не заданы, сервер сгенерирует их и напечатает две ссылки. Токены передаются во фрагменте URL (`#token=...&adminToken=...`), сохраняются только в `sessionStorage` и удаляются из адресной строки.

Основные переменные окружения:

```text
DEEPSEEK_API_KEY=sk-...
ACCESS_TOKEN=<длинный случайный секрет>
ADMIN_TOKEN=<другой длинный случайный секрет>
ALLOWED_HOSTS=helper.example.com
EXPERIENCE_DB_PATH=/data/experience.db
CONFIG_PATH=/data/web-config.json
MAX_CONCURRENT_CHATS=4
CHAT_GLOBAL_PER_MINUTE=60
```

`ACCESS_TOKEN=off` отключает пользовательскую авторизацию, но административный токен при внешнем доступе всё равно обязателен. Не публикуйте административную ссылку.

`TRUST_PROXY=1` включайте только за прокси, который удаляет присланный клиентом `X-Forwarded-For` и устанавливает собственный. Иначе сервер намеренно использует адрес TCP-соединения для rate-limit.

SQLite является обязательным хранилищем по умолчанию. JSON-режим включается явно через `EXP_DB_ENGINE=json`; аварийный fallback — только через `ALLOW_JSON_FALLBACK=1`. Это предотвращает незаметный переход на временное или непостоянное хранилище.

## Railway

1. Подключите репозиторий и используйте стандартную команду `npm start`.
2. Добавьте `DEEPSEEK_API_KEY`, `ACCESS_TOKEN` и `ADMIN_TOKEN`.
3. Создайте persistent volume, например `/data`, и задайте `EXPERIENCE_DB_PATH=/data/experience.db` и `CONFIG_PATH=/data/web-config.json`.
4. Создайте публичный домен. Railway передаёт `RAILWAY_PUBLIC_DOMAIN`; для собственного домена задайте `ALLOWED_HOSTS`.
5. Если входящие запросы действительно проходят через доверенный Railway proxy, задайте `TRUST_PROXY=1`.

Без persistent volume база опыта и изменяемый веб-конфиг пропадут при пересоздании контейнера.
