# 🎬 Operator Helper

Десктопный хелпер для онлайн-оператора вебкам-студии: AI-ассистент для чатов
(DeepSeek API), музыка для стрима и полная библиотека тип-меню.

## Запуск (режим разработки)

```bash
npm install     # один раз
npm start       # запуск приложения
```

## Сборка .exe

```bash
npm run dist    # готовые файлы появятся в папке dist/
```

## Первая настройка

1. Открой вкладку **⚙️ Настройки**.
2. Вставь API-ключ DeepSeek (получить: https://platform.deepseek.com).
3. Нажми «🔌 Проверить ключ» → затем «💾 Сохранить настройки».
4. Заполни **профиль модели** (имя, возраст, характер) — ассистент пишет ответы от её лица.

## Как работать с ассистентом

1. **＋ Добавить чат** — отдельный чат на каждого пользователя!
2. Вставь историю переписки как есть в большое поле.
3. Выбери стратегию (или оставь «Авто») и нажми **✨ Проанализировать** (Ctrl+Enter).
4. Скопируй «Лучший ответ» и отправь юзеру на площадке.
   Там же: альтернативные варианты, прогноз ответов юзера и логика решения.

## Файлы заготовок (папка `data/`)

- `Зазывы в приват.txt` — база фраз для AI (EN+RU). Можно дополнять своими строками
  в формате: английская строка, следующая строка — русский перевод.
- `tipmenu.json` — пункты тип-меню по категориям (редактируется любым текстовым редактором).

Ключ API и профиль модели хранятся локально на компьютере (`%APPDATA%/operator-helper`);
ключ шифруется через Electron `safeStorage` (DPAPI в Windows) и наружу не отдаётся.

## 🌐 Веб-версия (сайт)

Тот же хелпер работает в браузере — без установки и сборки Electron:

```bash
npm run web        # сервер на http://localhost:3000
```

Другой порт (PowerShell): `$env:PORT='8080'; npm run web`

- Интерфейс идентичный десктопу, открывается в любой вкладке браузера.
- **API-ключ хранится на стороне сервера** и никогда не возвращается браузеру —
  интерфейсу доступен только признак «ключ сохранён»; пустое поле ключа при
  сохранении означает «оставить прежний». Файл конфига лежит ВНЕ проекта — в
  `%APPDATA%/operator-helper/web-config.json` (старый `web/config.json` при первом
  запуске переносится туда автоматически и удаляется, чтобы не попасть в git).
- Защита: allowlist `Host` (анти-DNS-rebinding), проверка `Origin` на POST,
  JSON только с `Content-Type: application/json`, rate-limit `/api/chat` —
  20 зап./мин (прочие API — 60), заголовки `Cache-Control: no-store`, `nosniff`.
- Чаты, музыка и настройки профиля в браузере сохраняются через localStorage
  (истории автоудаляются через 30 дней или кнопкой «🧹 Очистить все чаты»).
- По умолчанию сервер слушает только `127.0.0.1` (доступ лишь с этого ПК).
  Если запустить с `HOST=0.0.0.0`, сервер при старте напечатает **токен доступа** —
  он обязателен для работы API: открой `http://<IP>:<PORT>/?token=<ТОКЕН>`
  (браузер запомнит его) или введи токен по подсказке на странице. Без токена
  все `/api/*` отвечают 401.

Обе версии используют одни и те же файлы интерфейса (`src/`) и заготовок
(`data/`) — любые правки сразу работают и в приложении, и на сайте.

## 🚀 Деплой на Railway

1. Репозиторий пушится на GitHub.
2. На [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo** → выбери репозиторий.
3. Railway сам определит Node.js и запустит `npm start` (это веб-сервер, порт подхватится автоматически).
4. В сервисе открой **Variables** и добавь:
   - `DEEPSEEK_API_KEY` = твой ключ DeepSeek — тогда в настройках сайта ничего вписывать не нужно.
5. **Settings → Networking → Generate Domain** — получишь публичную ссылку.

⚠️ Сайт публичный: любой, кто узнает ссылку, сможет пользоваться ассистентом
и расходовать твой ключ. Держи ссылку при себе либо попроси добавить авторизацию.

Файл `web/config.json` в облаке временный (файловая система Railway пересоздаётся
при каждом деплое), поэтому ключ задавайте переменной окружения.
