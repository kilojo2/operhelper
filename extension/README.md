# KILLASNAZZ для ShineBrowser

## Установка

1. В корне проекта выполните `npm run build:extension`.
2. Откройте в ShineBrowser страницу управления расширениями (`chrome://extensions`).
3. Включите режим разработчика и нажмите **Load unpacked / Загрузить распакованное**.
4. Выберите папку `dist/shine-extension`.
5. Закрепите KILLASNAZZ на панели браузера и нажмите его иконку.

Если версия ShineBrowser не поддерживает нативную боковую панель Chromium, расширение откроется в отдельной вкладке.

## Работа с чатами

- Автоматическое чтение и вставка поддерживаются на Chaturbate, Stripchat и BongaCams.
- Расширение только заполняет черновик. Оно никогда не нажимает кнопку отправки.
- Если площадка изменила разметку, вставьте переписку вручную и используйте кнопку копирования.
- Для импорта профиля откройте `https://operhelper.killasnazz.workers.dev/`, затем нажмите «Импорт с сайта» в настройках расширения.

API-ключ DeepSeek остаётся в Cloudflare Runtime Secrets и в расширение не включается.
